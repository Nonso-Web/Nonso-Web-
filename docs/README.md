# Portfolio website

This is the static portfolio website for Nonso Jude Okeleke. It is built with HTML, CSS and a small amount of JavaScript, with no build step or external framework.

## Publish with GitHub Pages

1. Open the repository: https://github.com/Nonso-Web/Nonso-Web-
2. Go to **Settings** → **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/docs**, then save.
5. After GitHub Pages finishes its first deployment, the site should be available at:

   https://nonso-web.github.io/Nonso-Web-/

## Updating the site

Edit `index.html`, `styles.css` or `script.js` in this folder and commit the changes to `main`. GitHub Pages will publish the update automatically.

## Content and data note

The portfolio project summaries link to the individual project folders in the repository. Their demonstration datasets are synthetic or illustrative and should not be represented as real operational data or validated engineering evidence.
